五分钟跑起来

需要 macOS 和 Xcode 命令行工具，没有别的前置。

# 装了哪个平台就采哪个，一个都没装也能跑
git clone https://github.com/scott987-cmd/quotient
cd quotient && swift build -c release

./.build/release/llmq collect   # 扫一遍本机
./.build/release/llmq report    # 看结果

想先试试又不想弄脏自己的配置：LLMQ_HOME=/tmp/试用 llmq collect， 整个数据目录挪到那儿，删掉就干净了。
