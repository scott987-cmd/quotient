使用支持

遇到问题时，请先运行 llmq doctor。它会说明本机识别到了哪些平台、共享目录和常驻服务。

额度没有显示

确认对应 CLI 已安装并产生过本地会话。需要剩余百分比的平台还要在 plans.json 中填写实际套餐上限；Quotient 不会猜套餐数字。

手机看不到 Mac

在 iOS App 中重新选择 iCloud Drive 里的 LLMQuotaBar 文件夹，并确认 Mac 上的定时采集已安装。同步依赖用户自己的 iCloud Drive。

没有收到通知

检查 iOS 通知权限、Mac 端 APNs 配置和共享目录中的设备登记。应用内仍可手动刷新并处理事项。

报告问题

请在 GitHub Issues 提交复现步骤、系统版本和 llmq doctor 的非敏感输出。不要上传令牌、密钥或真实任务内容。
