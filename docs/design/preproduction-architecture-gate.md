# 前置生产架构闸

## 决策

架构师的主要职责发生在实现任务创建之前，而不是在视觉评审失败后替实现者找补。
凡是声明了黄金样板的体验型生产任务，必须先有一份能覆盖目标结果、硬约束和验收方式的
生产设计；设计检查未通过时，调度器不得启动黄金样板，更不能进入批量扩张。

这条闸复用 `.llmq/project-contract.json`、`BENCHMARK.md`、`PRODUCTION.md` 和
`QUALITY.md`，不再增加一套平行的项目管理格式。

## 开工前必须锁定的内容

1. **最终结果**：玩家在目标设备上能直接感受到什么，不用功能数量代替质量目标。
2. **参考拆解**：只写可观察维度；明确哪些是机制参考，哪些表达不能复制。
3. **平台预算**：渲染器、目标设备、帧率、内存、包体、加载时延和离线约束。
4. **生产路线**：真实输入资产、来源/授权、工具、所需能力、质量上限和硬约束冲突。
5. **黄金样板**：只选一个最小但完整的垂直切片，写清正常运行时的交付形态。
6. **阶段验证**：源资产、DCC 黄金输出、引擎还原、正常流程证据、目标设备性能。
7. **停止条件**：出现哪种证据必须停止局部调参，退回架构层换路线。

## 状态流

```text
产品目标/参考
  → 前置生产设计通过
  → 黄金样板实现
  → DCC 黄金输出通过
  → 引擎还原与正常流程通过
  → 目标设备与独立体验票通过
  → 批量扩张
```

实现完成、测试通过或证据文件存在，都不能跨越前面的状态。批量扩张仍由现有
`GoldenSampleGate` 控制；本设计新增的是它前面的开工闸。

## 架构师与实现 Agent 的边界

- 架构师决定目标、路线、预算、黄金样板和否决条件，并批准路线变更。
- 原实现 Owner 在批准路线内连续施工，保持会话和项目上下文，不因普通失败换人。
- 独立验收只判证据是否达到契约，不代替实现者改代码，也不能擅自放宽契约。
- 同一根因连续两轮没有收敛，或实现需要放宽既有质量闸，自动视为路线风险，回到架构层。
- 接触距离、面数、构建结果等代理指标只能防回归，不能代替最终画面或手感。

## Flint 的前置决策

### 目标切片

只完成“岩 + K-7 + 一个实战小场景 + 待机/移动/射击/换弹 + 30–60 秒正常对局”。
该切片未通过之前，不新增角色、僵尸变体、地图或更多取证入口。

### 生产路线

- 使用授权明确的成熟人体、手部、骨骼、皮肤/眼睛/布料基础资产；原创身份通过造型、
  装备组合、材质和美术设计实现。
- Blender 用于装配、人工造型、绑定、动画重定向、握持姿势、烘焙、LOD 和 USDZ 导出。
- 程序脚本只负责确定性导出、批处理和验证，禁止从基础几何体/噪声生成英雄人物、皮肤、
  手部或关键装备并冒充成品资产。
- K-7 使用明确的右手握把、左手护木 socket 和人工校准/烘焙的四状态姿势；数值接触闸
  只能保持或收紧，放宽即为架构变更，不能由实现 Agent 自行决定。

### 双黄金门

1. **Blender 黄金画面**：固定相机和灯光下，身份、面部、材质、双手接触、装备贴合先达到
   参考标准。纯黑 Workbench 剪影只能作为轮廓辅助票，不能作为写实质量票。
2. **SceneKit 还原画面**：同人物、同武器、同动作、同机位进入真实 iOS 运行路径；如果
   DCC 达标而引擎未达标，解决导出、材质和运行时灯光，不回头用占位资产换通过。

### 停止条件

- 连续两轮只改参数或证据、参考机位画面没有明显改善。
- 为让测试变绿而扩大穿透、悬空、腕角或性能阈值。
- 新增的代码/截图没有改变正常入口中的实际画面。
- Blender 黄金画面本身仍是低模、塑料、占位或缺乏材质层次。

命中任一条时，保留原 Owner 和上下文，但暂停局部实现，由架构师修订生产路线后再继续。

## 已落地的系统闸

`GoldenSampleGate.prepare` 现在会先执行 `ProjectDoctor`。如果契约中的最终结果、参考文件、
生产路线、路线能力、阶段验证、验收条款或黄金样板绑定存在错误，任务在入队前直接失败，
不会再等视觉拒绝后才发现路线没设计完整。旧任务没有 `production` 元数据时行为保持不变。
