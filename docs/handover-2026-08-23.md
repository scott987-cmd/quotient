## 踩过就别再踩的形状（这个项目反复出的三类）

1. **同一概念多处判定** —— 同一个判断在两三处各写一份，条件细微不同，修一处漏一处。
   今天又抓到两例：「有 agent 在飞」三份、「仓库脏要不要让开」三份。加新判断前先 grep。
2. **文本当接口** —— 提示词子串契约、JSON 字段两侧各写一份。两侧各自测试都绿、拼起来才错。
3. **修好了到不了眼前** —— 代码存在但控制流走不到 / 发布到了错误位置 / 推给了做不了决定的人。
   今天最大的一例就是 Showcase（写了发布代码，但 agent 一跑就没人执行）。
