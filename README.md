# Quotient website

This repository publishes the [Quotient website](https://scott987-cmd.github.io/quotient/) from `docs/`. The current branch contains only the website, its approved media, and this README.

Current, separately maintained source releases:

- [Quotient Core](https://github.com/scott987-cmd/quotient-core): macOS CLI, menu-bar app, and multi-Mac coordination.
- [Quotient Mobile](https://github.com/scott987-cmd/quotient-mobile): iPhone/iPad client. The public October 8 snapshot predates the October 9 App Review build.

The [App Store status page](https://scott987-cmd.github.io/quotient/app-store-readiness.html) distinguishes simulator tests, physical-device evidence, and Apple's review state. Quotient does not provide model subscriptions or cloud model credits. End-to-end game production remains experimental and requires separate playable-build acceptance.

Earlier Git commits and forks of this repository can still contain retired source and operational QA records. Removing those files from the current branch does not erase their history. Do not use old commits as current build instructions.
